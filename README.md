# Nexus · Recorrido 3D para Windows

[**Descargar aplicación para Windows (ZIP)**](https://github.com/avarelavi1024/nexus-recorrido-windows/releases/latest/download/Nexus-Recorrido-Windows.zip)

Descomprime el ZIP y abre **Nexus-Recorrido.exe**. No necesitas instalar Godot ni tener una cuenta de GitHub. La aplicación funciona sin conexión a Internet.

Recorrido de referencia para revisar la distribución y los acabados de un gimnasio: entrada, recepción, cafetería, salas y vestuarios. Este repositorio publica únicamente el visor y sus instrucciones; el proyecto de trabajo permanece privado.

## Controles

- WASD o flechas: caminar. Ratón: mirar. Shift: correr. Esc: liberar ratón.
- 1: entrada; 2: recepción; 3: cafetería; 4–6: salas; 7: clases; 8: vestuarios; 9: pasillo.
- Tab: vista general. F1: ayuda. V: vuelo, E/Q subir/bajar.
- N: escribir una nota, Enter: guardar. F12: captura.

Notas y capturas locales: `%APPDATA%\Nexus Recorrido 3D\notas`. No se envían a ningún servidor. Para compartir observaciones, envía esa carpeta por el medio que prefieras.

Windows 10/11 de 64 bits. Si hay problemas gráficos, utiliza **Modo-compatible.cmd** incluido en el ZIP. El ejecutable no tiene firma digital de editor comercial.

Esta maqueta sirve para revisar el concepto; no sustituye planos técnicos ni mediciones del local. Altura de 3,5 m provisional.
